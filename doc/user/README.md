# Codeenstein 3D — Player Guide

Codeenstein 3D turns a folder of source code into a playable retro raycaster dungeon: every file is a level, every function in it is both a room and the enemy waiting inside, and the folder tree is the order you play them in. This guide covers everything you need to actually play — for the project pitch and dev setup, see the top-level [`README.md`](../../README.md).
